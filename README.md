# ERAQO Store

Aplikasi resmi **ERAQO Store** — toko online ERAQO untuk Android. Belanja produk ERAQO, cek promo & voucher, dan lacak pesanan kamu langsung dari HP.

## 📲 Download APK

Unduh versi terbaru di halaman **[Releases](https://github.com/eraqo2026apps/eraqostore-releases/releases)**.

Cari file dengan nama `eraqostore-vX.X.X.apk`, lalu install seperti biasa di HP Android kamu.

## Fitur

- Belanja produk ERAQO langsung dari aplikasi
- Pembayaran online (Bank Transfer, QRIS, GoPay, ShopeePay)
- Voucher & diskon
- Notifikasi status pesanan real-time
- Riwayat & tracking pesanan

## Catatan Instalasi

Karena APK ini diunduh dari luar Google Play Store, Android mungkin akan menampilkan peringatan "Install unknown app". Ini normal — cukup izinkan instalasi dari sumber ini untuk melanjutkan.
